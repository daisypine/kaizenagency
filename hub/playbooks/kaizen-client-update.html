Kaizen Client Update (monthly report + gameplan)

Every retainer client gets one update page a month, sent on the first business day. House examples: Adapt AHC-ACW/september-october.html (client format), Adapt AHC-ACW/aug-sept-oct.html (internal format), JDH jdh-october-plan/index.html, Falcon falcon-roofing/october-november.html. Repo: github.com/daisypine/kaizenagency (GitHub Pages: daisypine.github.io/kaizenagency/).

Two formats

  • Client update (default): "[Client] [Month] Update". Warm, first person from Daisy, ~1,000 words. Goes to the client.

  • Internal gameplan: "[Client] - [Months] Gameplan (Internal)". Terse, tables, dark header, footer "Internal - Kaizen Agency. Client-facing version to be built separately." Never send to the client.

1. Gather (before writing)

  • GA4 (daisy@kaizenagency.org, authuser=...): Traffic acquisition for the month: sessions, organic sessions, key events (phone_call, lead_form_start). Use the property picker search; don't trust the property that opens by default.

  • GSC (sc-domain property): clicks, impressions, CTR, avg position for the month and the month before; top queries with high impressions and low CTR.

  • Looker Studio: if the client has a live report, screenshot the monthly chart into the client folder (e.g. oct-2026-report.png) and link it under Quick links. If not, add "set up Looker Studio" to next month (copy the Adapt report, swap the GA4 + GSC sources).

  • GBP: calls, direction requests, reviews this month if available.

  • CRM (Housecall Pro / Jobber / Jane): leads, booked jobs, revenue if the client's plan includes it.

  • Work done: the client's Cleanup Log, task board Done column, sent emails, Drive docs from the month.

  • Plan: the client's Content Calendar / sitemap phases, and any commitments in email.

2. Client update structure (in order)

  1. Top bar: client logo (inline it as a data: URI if publishing as a Claude artifact; hotlink is fine on GitHub Pages) with a text wordmark fallback. Kaizen only in the footer.

  2. Hero: eyebrow "[Month] [Year] update"; H1 "Your [last month] report + the plan for [this month]"; lede addressing the client by name, ending "Bookmark this one (:"

  3. Quick links: tiles for the live report and the month's working docs (email plan, content plan, sitemap sheet). Bold title + one-line "what it's for".

  4. [Month] report: chart screenshot if there is one, 1-2 plain paragraphs leading with the good news and explaining any dip, then 4 stat tiles (big number + caption in client words). Name the single biggest opportunity.

  5. What we did in [month]: bullets in client language (outcomes, not plugin names).

  6. What we're working on in [month]: label/content rows: New pages, Site cleanup, Blogs, Reviews, Email + text, Social, Design, Google profile. Each item gets one sentence of "why" in client terms.

  7. Optional client-specific sections: an issue they raised ("Figured it out!"), sample social posts, an upsell idea with a CTA button, a "Done" badge for a resolved admin item, how-to steps.

  8. Coming up: rows for the next 1-2 months.

  9. What's in your monthly package (only if the client's package is documented; never invent it, never show prices or Kaizen fees).

  10. Direct access to me: (408) 710-6718, daisy@kaizenagency.org.

  11. What I need from you: numbered asks, bold lead + question. Max 6.

  12. Footer: "If there's something you want moved up the list, just say the word!
    Daisy · Kaizen Agency".

3. Design

  • Single self-contained HTML, inline CSS, Outfit (display) + Poppins (body), meta robots noindex.

  • Tokens: --bg, --surface, --fg, --muted, --line, --accent, --accent-dark, --accent-soft, --accent-fg. The accent is the CLIENT's brand color (Adapt green #008067; Falcon gold #8A6400 light / #E8B923 dark). Check contrast on white.

  • Components: .links/.link, .shot, .stats/.stat, .rows/.row/.k, .cal (date pill + item), .done, .steps, .cta, .note, .flag (warning), .contact, .need. Card max-width 780px; rows stack under 520px.

  • Copy: Daisy's voice: warm, casual, short paragraphs, "(:", light "!". Plain English, no jargon.

4. Rules

  • Only real numbers from GA4/GSC/CRM with the date range stated. If tracking is new, say it's the baseline.

  • No customer names, street addresses or prices without OK. Reviews: real only, first name + city.

  • No Kaizen fees. No referral rewards for contractors (CA B&P 7157).

  • Don't claim work that isn't done; check the Cleanup Log.

5. Publish + send

  1. Draft as a private Claude artifact for Daisy's review.

  2. On her OK, commit to the repo: <client-folder>/<lastmonth>-<month>.html (+ report PNG beside it), then check the live GitHub Pages URL loads.

  3. Draft the email in Gmail (business account) to the client: short, Daisy's voice, 3-4 bullet highlights, the link, and the top 1-2 asks. Never send without Daisy's go-ahead.

  4. Log it: add the link to the client's sitemap sheet Overview and the Content Calendar row for the report.

Public page. No passwords, keys, client contact details or prices here; those live in Drive and the workspace.
